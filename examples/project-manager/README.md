# Samrey Project Manager (Phase 18 Real-World Consumer)

> **Samrey Framework v1.0.0-rc.1** — Reference enterprise application demonstrating 100% native Samrey architecture.

This production-grade consumer application showcases:
- **State Management**: `@samrey/reactivity` (`createStore`, `produce`, `signal`, `computed`, `batch`)
- **UI & Control Flow**: `@samrey/runtime` (`el`, `Show`, `For`, `Switch`, `Match`, `ErrorBoundary`, `Modal`, `mount`)
- **Forms & Validation**: `@samrey/forms` (`createForm`, `createField`, `getAccessibleFieldProps`) with Standard Schema (`~standard` v1)
- **HTTP & Cache**: `@samrey/http` (`createHttpCache`, async resources)
- **Zero-Trust Security**: `@samrey/security` (`sanitizeHtml`, `sanitizeUrl`, `createCsrfToken`, `validateCsrfToken`)
- **Full-featured Modules**: Project Portfolio, Kanban Task Management, Live Security Sandbox, Optimistic Updates, Toast Notifications Queue, and Responsive Design.
