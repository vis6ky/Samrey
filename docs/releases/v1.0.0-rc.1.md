# Release Notes — Samrey Framework v1.0.0-rc.1

**Release Candidate 1 (Public Beta Preparation)**  
*Date: August 20, 2026*  
*License: Apache-2.0*

Samrey is a next-generation TypeScript web framework built from the ground up on fine-grained reactivity, compile-time static template cloning, and zero virtual DOM overhead.

---

## 🌟 Highlights

1. **True Fine-Grained Reactivity**: State updates bypass the component tree completely and update exactly the single DOM text node or attribute that depends on the signal.
2. **Minimal Bundle Footprint**: Ultra-lean runtime (6.29 kB baseline runtime) with tree-shakable modular packages.
3. **End-to-End Security Architecture**: Built-in W3C Trusted Types, contextual attribute sanitizers, anti-CSRF token verification, and automated SSR secret stripping.
4. **Isomorphic Streaming SSR & Resumable Hydration**: Asynchronous HTML streaming with inline event capture buffers and zero full-tree re-rendering.
5. **Standard Schema Form Validation**: Native interoperability with any standard validation library (Zod, Valibot, ArkType) with automated ARIA state management.

## 🚀 Quick Start

```bash
# Initialize a new project with the Samrey CLI
npx @samrey/cli create my-app --template ssr

# Navigate to project and start the development server
cd my-app
npm install
npm run dev
```

## 🛡️ Security Verification
- **Zero dynamic code execution**: No `eval()` or `new Function()` anywhere in compiler or runtime.
- **Automated Secret Stripping**: Server-side credentials cannot accidentally leak into hydration payloads.
- **Strict Content Security Policy**: Native compliance with strict CSP rules.
