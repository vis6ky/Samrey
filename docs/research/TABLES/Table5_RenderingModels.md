# Table 5: Rendering Paradigms & Structural Execution Comparison

| Paradigm Dimension | Virtual DOM (e.g. React 19) | Hybrid VDOM (e.g. Vue 3.5) | Incremental DOM (e.g. Angular 19 Ivy) | Compiler Runes (e.g. Svelte 5) | Samrey Native Architecture |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Component Execution Frequency** | Re-executes on every state change ($O(\text{Tree Depth})$ calls) | Re-executes component render function upon proxy update | Component view checked in dirty digest loop or Signal notification | Executes once to wire reactive graph; runes update DOM | **Executes exactly once during initial mount**; never re-executes |
| **DOM Creation Mechanism** | Recursive virtual node object allocations (`React.createElement`) | Compiler-generated VNode block trees with patch flags | Sequential Ivy bytecode interpreter instructions (`elementStart`) | Direct imperative DOM creation helpers generated by compiler | **Static HTML `<template>` cloning (`cloneNode(true)`)** |
| **Update Propagation Path** | Virtual DOM reconciliation diffing (Fiber tree work loop) | Patch flag bitmask comparisons skipping static children | LView array scanning and slot value comparison | Direct fine-grained reactive subscriptions | **Direct element property and text updates via signal closures** |
| **Intermediate Tree Allocations** | Full VDOM mirror tree allocated and garbage collected per tick | Block VNode trees allocated on dynamic state changes | Incurs internal LView array maintenance allocations | Near zero runtime tree allocations | **Strictly zero intermediate tree objects allocated on mutation** |
| **Hydration Strategy** | Full client VDOM tree regeneration matching server HTML | Full client VDOM hydration matching server markup | Progressive hydration with event replay (Blocks) | DOM traversal with marker comments | **Resumable micro-hydration: direct event delegation resumption** |
| **Security by Default** | Basic text escaping; dynamic HTML requires manual caution | Text escaping; `v-html` requires developer sanitization | DomSanitizer with bypass escape hatches | Text escaping; `{@html}` bypasses | **Contextual compiler classification + Trusted Types + Zero `eval`** |
