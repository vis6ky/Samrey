# Grok Integration & CLI Fallback Guide

Grok (xAI) can be utilized with Samrey projects via instruction context and the Samrey CLI fallback.

## Integration Mechanisms

### 1. Repository Instructions (`AGENTS.md`)
Place `AGENTS.md` at your repository root. When prompting Grok in a workspace with file attachment capabilities, attach `AGENTS.md` as context.

### 2. CLI Command Tooling Fallback
Since Grok does not currently support native local stdio MCP server spawning directly inside an editor IDE, use the Samrey CLI fallback:

```bash
# Search documentation for Grok
npx @samrey/cli ai docs "createResource"

# Validate code generated by Grok
npx @samrey/cli ai validate generated-component.ts

# Run the health doctor
npx @samrey/cli ai doctor
```

### 3. API Tool Call Integration
If building an agent pipeline with Grok's function-calling API, map Grok's tool calls directly to the `@samrey/ai` programmatic engine:

```ts
import { validateSamreyCode, searchDocs, getDocumentation } from '@samrey/ai';

// When Grok calls search_docs
const docs = searchDocs(args.query);

// When Grok calls validate_code
const result = validateSamreyCode(args.code);
```
