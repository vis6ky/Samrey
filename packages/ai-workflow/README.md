# @samrey/ai-workflow

Autonomous AI Application Development & Self-Correction Engine for the Samrey Framework.

## Features
- Structured autonomous development workflow orchestration (`WorkflowEngine`)
- Application architecture and contract planning (`ArchitecturePlanner`)
- Automated self-correction for framework violations (`SelfCorrectionEngine`)
- Trace logging and observability (`TraceLogger`)
- Role-based file and execution safety enforcement (`SecurityPolicy`)
