# @samrey/ai

Universal AI Development Integration, Knowledge Engine & Validation Suite for the **Samrey** reactive web framework.

## Overview

`@samrey/ai` provides a complete intelligence and integration layer enabling any modern AI coding assistant (Google Gemini, Claude, Cursor, GitHub Copilot, ChatGPT, Grok, Windsurf) to natively understand Samrey's compile-time reactive architecture, generate accurate Samrey code, diagnose compiler errors, and build full-scale applications.

## Key Capabilities

- **Framework Discovery**: Automatically detects installed Samrey packages, versions, project features (SSR, routing, forms, http), and configuration files.
- **Documentation Engine**: High-speed, structured, version-aware documentation and API reference lookup across all 11 official packages.
- **Example Engine**: 25+ verified, production-grade native Samrey code examples covering reactivity, components, routing, forms, SSR, and testing.
- **Project Analyzer**: Deep structural analysis of Samrey applications, component hierarchies, and anti-pattern detection (flagging React/Vue/Angular idioms).
- **Code Validator**: In-memory compilation and semantic analysis of AI-generated code using `@samrey/compiler` and AST linting.
- **Diagnostics Engine**: Structured root-cause explanations and automated code transformations for compiler errors (`SAMREY-101` through `SAMREY-108`).
- **Compatibility Suite**: 13 automated benchmark tasks verifying that an AI agent or model generates valid, compilable, runnable Samrey applications.
- **Instruction Generators**: Synchronized authoritative instruction files for `AGENTS.md`, `GEMINI.md`, `CLAUDE.md`, `.github/copilot-instructions.md`, and `.cursor/rules/samrey.mdc`.
- **Portable Skills**: 10 Agent Skills conforming to the Agent Skills specification.
