# `@aether/compiler`

Ahead-of-Time template compiler, Aether Intermediate Representation (AIR) generator, contextual security classifier, and static `<template>` hoister.

## Key Features

- Generates Intermediate Representation (AIR).
- Completely decoupled from runtime internals.
- Static A11y and Security linting passes.
- Direct output code targeting `@aether/runtime`.
