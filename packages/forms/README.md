# `@aether/forms`

Type-safe reactive form container, Standard Schema (~v1) integration, fine-grained field state tracking, and automated ARIA accessibility attributes.

## Features

- Standard Schema (~v1) compatible.
- Reactive `dirty`, `touched`, `error`, `valid` signals per field.
- Auto-generates `aria-invalid`, `aria-describedby`, and `aria-errormessage`.
